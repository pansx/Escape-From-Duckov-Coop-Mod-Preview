# Patch/Projectile 模块 API 文档

## 模块概述

Projectile 补丁模块拦截投射物逻辑，实现客户端预测和服务器权威的命中判定，防止客户端作弊。

## 补丁目标

- `FakeProjectile` - 假投射物（客户端视觉效果）

## 核心补丁说明

### FakeProjectilePatch

**补丁目标**：FakeProjectile 类

**可能拦截的方法**：

- 投射物生成

- 投射物命中检测

- 投射物销毁

**设计思路**：

- **客户端**：生成假投射物用于视觉反馈（轨迹、特效）

- **服务器**：进行真实的命中判定和伤害计算

- **目的**：避免客户端作弊（如修改弹道、穿墙等）

## 关键流程

### 投射物同步流程

```

客户端 → 生成假投射物（视觉） → 发送投射物数据
服务器 → 模拟投射物轨迹 → 计算命中
      → 广播命中结果 → 所有客户端
客户端 → 播放命中特效

```

## 设计模式

**客户端预测 + 服务器权威**：

- 客户端立即显示投射物轨迹（低延迟体验）

- 服务器计算真实命中（防作弊）

- 客户端根据服务器结果校正

## 防作弊机制

1. **客户端只负责视觉**：
   - 假投射物不进行真实碰撞检测

   - 不计算伤害

2. **服务器权威判定**：
   - 服务器重新模拟投射物轨迹

   - 服务器计算命中和伤害

   - 广播权威结果

3. **数据验证**：
   - 验证投射物初始位置和速度

   - 检测异常数据（如超高速度）
