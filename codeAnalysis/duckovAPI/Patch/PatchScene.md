# Patch/Scene 模块 API 文档

## 模块概述

Scene 补丁模块拦截场景相关逻辑，实现场景切换、门状态、关卡管理的网络同步。

## 补丁目标

- `Door` - 门系统

- `LevelManager` - 关卡管理器

- `Scene` - 场景系统

## 文件列表

| 文件名 | 补丁目标 | 说明 |

|--------|---------|------|
|---|---|---|

| `LevelManagerPatch.cs` | LevelManager | 关卡管理器补丁 |
|---|---|---|

## 核心补丁说明

### DoorPatch

**补丁目标**：Door 类

**可能拦截的方法**：

- 门开关操作

- 门状态变化

**用途**：

- 同步门状态到所有玩家

- 防止门状态不一致

### LevelManagerPatch

**补丁目标**：LevelManager 类

**可能拦截的方法**：

- 关卡加载

- 关卡切换

- 关卡初始化

**用途**：

- 同步关卡状态

- 触发网络初始化

- 管理场景切换流程

### ScenePatch

**补丁目标**：Scene 相关类

**可能拦截的方法**：

- 场景加载

- 场景卸载

**用途**：

- 同步场景切换

- 清理网络状态

- 重置 AI 和物品

## 关键流程

### 场景切换流程

```

LevelManagerPatch (Prefix)
  ↓
主机 → 发起场景切换 → 广播切换命令
客户端 → 接收命令 → 加载场景
  ↓
ScenePatch (Postfix)
  ↓
所有客户端 → 加载完成 → 同步场景状态

```

### 门状态同步流程

```

DoorPatch (Postfix)
  ↓
玩家 → 开关门 → 广播门状态
其他客户端 → 接收 → 更新门状态

```

## 注意事项

1. **场景切换时机**：
   - 确保所有客户端准备就绪

   - 使用投票系统（如撤离）

2. **状态清理**：
   - 场景切换时清理旧场景数据

   - 重置 AI、物品、玩家状态

3. **加载同步**：
   - 等待所有客户端加载完成

   - 使用加载进度同步
