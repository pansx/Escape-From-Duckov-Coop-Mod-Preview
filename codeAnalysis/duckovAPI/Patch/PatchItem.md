# Patch/Item 模块 API 文档

## 模块概述

Item 补丁模块拦截物品相关操作，包括手雷、枪械、物品掉落拾取等，实现物品状态的网络同步。

## 补丁目标

- `Grenade` / `Breakable` - 手雷和可破坏物

- `Gun` - 枪械

- `Item` - 物品基类

- `ItemExtensions` - 物品扩展方法

- `ItemUtilities` - 物品工具

- `Slot` - 槽位系统

## 核心补丁说明

### Grenade_BreaKablePatch

**用途**：

- 同步手雷投掷

- 同步爆炸效果

- 同步爆炸伤害

### GunPatch

**用途**：

- 同步射击事件

- 同步换弹

- 同步瞄准状态

- 同步弹药数量

### ItemPatch

**用途**：

- 同步物品掉落

- 同步物品拾取

- 同步物品使用

- 防止重复拾取

### SlotPatch

**用途**：

- 同步装备操作

- 同步槽位变化

- 同步装备/卸下

## 关键流程

### 射击同步流程

```

客户端 → 本地射击 → 发送射击事件
服务器 → 验证并广播 → 所有客户端
客户端 → 播放射击特效

```

### 物品掉落流程

```

客户端 → 生成本地物品 → 发送掉落请求
服务器 → 验证并分配 ID → 广播物品生成
客户端 → 创建物品

```
