# TeamSoda.Duckov.Utilities 模块分析

## 概述

Utilities 模块提供了游戏开发中常用的工具类和基础设施，包括数据管理、对象池、随机工具等核心功能。

## 核心组件

### CustomData (自定义数据系统)

- **功能**：类型安全的动态数据存储系统

- **支持类型**：- `Float`: 浮点数

  - `Int`: 整数

  - `Bool`: 布尔值

  - `String`: 字符串

  - `Raw`: 原始字节数据

- **特性**：- 类型安全访问

  - 本地化显示名称支持

  - 事件通知机制 (`OnSetData`)

  - 二进制序列化

### Tag (标签系统)

- **功能**：游戏对象分类和过滤系统

- **关键属性**：- `Priority`: 优先级排序

  - `Color`: 视觉标识

  - `Show/ShowDescription`: 显示控制

  - `Hash`: 高效比较

- **本地化**：支持多语言标签名称和描述

- **用途**：物品分类、插槽过滤、效果触发条件

### PrefabPool<T> (对象池系统)

- **功能**：高性能的预制体对象池管理

- **特性**：- 泛型设计，支持任意 Component 类型

  - 自动生命周期管理

  - 可配置容量和最大大小

  - 支持 `IPoolable` 接口回调

- **生命周期回调**：- `onCreate`: 对象创建时

  - `onGet`: 从池中获取时

  - `onRelease`: 释放回池时

  - `onDestroy`: 对象销毁时

### RandomUtilities (随机工具)

- **功能**：扩展的随机数工具集

- **主要方法**：- `RandomizeOrder<T>()`: 列表随机排序

  - `GetRandom<T>()`: 随机选择元素

  - `GetRandomSubSet<T>()`: 随机子集选择

  - `GetRandomWeighted<T>()`: 权重随机选择

- **支持**：Unity Random 和 System.Random

### IUpdatable (更新接口)

- **功能**：统一的更新机制抽象

- **方法**：`OnUpdate()` - 定期更新调用

- **用途**：游戏循环中的对象状态更新

## 设计模式

### 泛型设计

- `PrefabPool<T>` 使用泛型提供类型安全

- `RandomUtilities` 扩展方法支持任意类型

### 接口隔离

- `IUpdatable` 只定义必要的更新方法

- `IPoolable` 提供池化对象的生命周期回调

### 事件驱动

- `CustomData` 的数据变更通知

- 对象池的生命周期事件

### 类型安全机制

- 严格的类型检查

- 类型不匹配时的警告和默认值返回

- 防止意外的类型转换

## 本地化支持

### 标签本地化

- 自动生成本地化键值 (`Tag_[name]`)

- 支持描述文本本地化

- 与 SodaCraft.Localizations 集成

### 自定义数据本地化

- 变量显示名称本地化 (`Var_[key]`)

- 统一的本地化键值管理

## 性能优化

### 对象池优化

- 减少 GC 压力

- 预分配对象减少实例化开销

- 可配置的池大小限制

### 哈希缓存

- Tag 系统使用哈希值加速比较

- 延迟计算和缓存机制

### 扩展方法

- 避免额外的包装类

- 直接在集合类型上提供功能

## 开发建议

### 使用 CustomData

- 适合存储动态配置数据

- 类型安全访问避免错误

- 支持序列化和本地化

### 标签系统最佳实践

- 使用有意义的标签名称

- 合理设置优先级

- 利用颜色进行视觉区分

### 对象池使用

- 频繁创建销毁的对象使用池化

- 实现 `IPoolable` 接口处理池化逻辑

- 合理设置池大小避免内存浪费

### 随机工具应用

- 使用权重随机实现概率系统

- 子集选择用于随机奖励

- 列表随机化用于内容变化
