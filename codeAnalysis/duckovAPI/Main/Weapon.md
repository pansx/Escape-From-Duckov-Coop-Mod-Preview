# Main/Weapon 模块 API 文档

## 模块概述

Weapon 模块负责武器系统的网络同步，包括射击、换弹、武器切换等。

## 文件列表

共5个文件，负责武器同步的各个方面。

## 核心功能

- 射击事件同步

- 换弹同步

- 武器切换同步

- 弹药状态同步

- 射击特效同步

## 关键流程

### 射击同步流程

```

客户端 → 本地射击 → 发送射击事件
服务器 → 验证并广播 → 所有客户端
客户端 → 播放射击特效和音效

```

### 换弹同步流程

```

客户端 → 开始换弹 → 发送换弹事件
服务器 → 广播 → 所有客户端
客户端 → 播放换弹动画

```

## 依赖关系

**依赖模块**：

- NetService - 网络通信

- Main/FxManager - 特效管理

**被依赖模块**：

- Patch/Item/GunPatch - 枪械补丁
