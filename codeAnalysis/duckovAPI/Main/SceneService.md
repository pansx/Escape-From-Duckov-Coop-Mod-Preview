# Main/SceneService 模块 API 文档

## 模块概述

SceneService 模块负责场景服务，包括场景切换、投票系统、场景同步等。这是联机模组中最复杂的模块之一。

## 文件列表

共8个文件，负责场景管理的各个方面。

## 核心功能

- 场景切换同步

- 投票系统

- 场景加载管理

- 场景状态同步

- 撤离点管理

## 关键流程

### 场景切换流程

```

主机 → 发起场景切换 → 广播切换命令
客户端 → 接收命令 → 加载场景
所有客户端 → 加载完成 → 同步场景状态

```

### 投票流程

```

玩家 → 发起投票 → 服务器
服务器 → 广播投票 → 所有客户端
客户端 → 投票 → 服务器
服务器 → 统计结果 → 执行操作

```

## 依赖关系

**依赖模块**：

- NetService - 网络通信

- Main/AI - AI 场景同步

**被依赖模块**：

- Patch/Scene - 场景补丁
