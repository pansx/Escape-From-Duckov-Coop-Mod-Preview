# Main/WeatherAndTime 模块 API 文档

## 模块概述

WeatherAndTime 模块负责天气和时间系统的网络同步，确保所有客户端的天气和时间状态一致。

| 文件名 | 说明 |

|--------|------|
|---|---|

## 核心功能

- 天气状态同步

- 时间同步

- 昼夜循环同步

- 天气变化同步

## 关键流程

### 天气同步流程

```

服务器 → 天气变化 → 广播天气状态
客户端 → 接收并应用天气

```

### 时间同步流程

```

服务器 → 定期广播时间 → 所有客户端
客户端 → 接收并同步时间

```

## 依赖关系

**依赖模块**：

- NetService - 网络通信

**Unity 依赖**：

- 游戏的天气系统

- 游戏的时间系统
