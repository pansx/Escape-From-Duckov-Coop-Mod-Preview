# Duckov 游戏 API 参考文档

## API 文档来源

游戏 API 文档位于 `codeAnalysis/duckovAPI` 目录中。这包含了"逃离鸭堡"模组开发的官方 API 规范，应在所有游戏相关集成中参考使用。

## 可用的核心 API 系统

基于 duckovAPI 文档，以下系统可用：

-   **游戏核心系统** - 角色控制、关卡管理、制作系统
-   **物品系统** - 完整的物品管理和统计
-   **工具系统** - 数据管理和对象池
-   **本地化系统** - 多语言支持
-   **经验系统** - 等级和进度管理
-   **存档系统** - 数据持久化
-   **音频系统** - 声音和音乐管理
-   **模组系统** - 模组开发和管理
-   **选项系统** - 游戏设置管理
-   **难度系统** - 游戏规则和难度管理
-   **成就系统** - 成就解锁和统计
-   **任务系统** - 任务管理和执行
-   **经济系统** - 货币和商店管理
-   **增益系统** - 增益/减益效果
-   **UI 系统** - 界面和交互管理
-   **效果系统** - 视觉和文本效果

## 开发指南

### 语言要求

-   **代码注释**: 使用中文进行代码注释和文档编写
-   **变量命名**: 在适当的地方使用中文命名约定
-   **API 调用**: 严格遵循 duckovAPI 文档中的 API 规范
-   **错误消息**: 面向用户的内容显示中文错误消息
-   **类/方法名**: 在适当的地方使用中文命名约定

### API 集成规则

-   在实现游戏相关功能之前，始终参考 duckovAPI 文档
-   不要假设或猜测 API 端点、参数或数据结构
-   使用文档中指定的确切方法签名和数据类型
-   遵循 API 文档中定义的身份验证和连接模式
-   在适用的地方利用现有的游戏系统（网络、玩家管理等）

### Steam P2P 集成指南

-   将 Steam P2P 网络与现有游戏的网络层集成
-   使用 duckovAPI 中现有的玩家和会话管理系统
-   确保与游戏模组系统架构的兼容性
-   遵循游戏的事件系统模式处理网络事件
-   利用游戏的 UI 系统构建大厅界面

### 代码质量标准

-   遵循 C# 类型安全的最佳实践
-   为 Steam 和游戏 API 调用实现适当的错误处理
-   对网络操作使用 async/await 模式
-   保持 Steam 网络和游戏逻辑之间的清晰分离
-   遵循游戏现有的代码模式和约定
-   使用中文注释和文档以提高可读性

## 编译脚本

项目使用 `./build.bat` 作为主要编译脚本。运行此脚本来构建整个项目。
