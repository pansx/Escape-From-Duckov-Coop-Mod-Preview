# 玩家渲染同步机制分析

## 概述

这个 Mod 实现了一个完整的多人联机系统，包括玩家的创建、渲染、同步和重连机制。

## 核心数据结构

### 1. 玩家管理容器

**主机端 (Server)**:
- `remoteCharacters: Dictionary<NetPeer, GameObject>` - 存储每个客户端对应的远程角色对象
- `playerStatuses: Dictionary<NetPeer, PlayerStatus>` - 存储每个客户端的状态信息

**客户端 (Client)**:
- `clientRemoteCharacters: Dictionary<string, GameObject>` - 按玩家ID存储其他玩家的角色对象
- `clientPlayerStatuses: Dictionary<string, PlayerStatus>` - 按玩家ID存储其他玩家的状态

### 2. PlayerStatus 结构

包含玩家的完整状态信息：
- `EndPoint` - 玩家唯一标识符
- `PlayerName` - 玩家名称
- `Position/Rotation` - 位置和旋转
- `IsInGame` - 是否在游戏中
- `SceneId` - 当前场景ID
- `CustomFaceJson` - 自定义外观数据
- `EquipmentList/WeaponList` - 装备和武器列表

## 玩家创建流程

### 主机端创建远程玩家

**文件**: `CreateRemoteCharacter.cs` -> `CreateRemoteCharacterAsync()`

```csharp
// 1. 检查是否已存在

// 2. 克隆本地主角色作为远程玩家

// 3. 加载角色物品数据

// 4. 禁用物理和AI组件（MakeRemotePhysicsPassive）
// - 禁用 AICharacterController, NavMeshAgent, CharacterController
// - 设置 Rigidbody 为 Kinematic
// - 禁用 Animator 的 root motion

// 5. 应用自定义外观
if (!string.IsNullOrEmpty(customFaceJson)) {
    var customFaceData = JsonUtility.FromJson<CustomFaceSettingData>(customFaceJson);
    characterModel.characterModel.CustomFace.LoadFromData(customFaceData);
}

// 6. 清空装备槽位
COOPManager.ChangeArmorModel(cm, null);

instance.AddComponent<RemoteReplicaTag>();  // 标记为远程副本
```

## 玩家同步机制

### 1. 位置同步 (POSITION_UPDATE)

**发送频率**: 每 0.015 秒 (约 67Hz)

**发送端** (`SendLocalPlayerStatus.cs`):

```csharp
public void SendPositionUpdate() {
    var cmc = CharacterMainControl.Main;
    var position = cmc.transform.position;
    var forward = cmc.modelRoot.transform.forward;
    
    writer.Reset();
    writer.Put((byte)Op.POSITION_UPDATE);
    writer.Put(localPlayerStatus.EndPoint);
    writer.PutV3cm(position);  // 量化压缩（厘米精度）
    writer.PutDir(forward);     // 方向向量压缩
    
    // 使用 Unreliable 通道，允许丢包
    if (IsServer) netManager.SendToAll(writer, DeliveryMethod.Unreliable);
    else connectedPeer.Send(writer, DeliveryMethod.Unreliable);
}
```

**接收端** (`Mod.cs` -> `OnNetworkReceive`):
```csharp
case Op.POSITION_UPDATE:
    var endPoint = reader.GetString();
    var pos = reader.GetV3cm();  // 解压位置
    var dir = reader.GetDir();   // 解压方向
    var rot = Quaternion.LookRotation(dir, Vector3.up);
    
    // 更新状态
    if (clientPlayerStatuses.TryGetValue(endPoint, out var st)) {
        st.Position = pos;
        st.Rotation = rot;
    }
    
    // 推送到插值器
    if (clientRemoteCharacters.TryGetValue(endPoint, out var go)) {
        var ni = NetInterpUtil.Attach(go);
        ni?.Push(pos, rot);  // 平滑插值
    }
```

**插值器** (`NetInterpolator.cs`):
- 使用时间轴模式进行平滑插值
- 支持硬对齐（误差过大时直接传送）
- 使用 EMA（指数移动平均）追踪速度

### 2. 动画同步 (ANIM_SYNC)

**发送频率**: 每 0.015 秒

**同步参数**:
- `moveSpeed` - 移动速度
- `moveDirX/Y` - 移动方向
- `isDashing` - 是否冲刺
- `isAttacking` - 是否攻击
- `handState` - 手部状态
- `gunReady` - 枪械准备状态
- `stateHash` - 动画状态哈希
- `normTime` - 归一化时间

**接收处理**:
```csharp
var ai = AnimInterpUtil.Attach(remoteObj);
ai?.Push(new AnimSample {
    speed = moveSpeed,
    dirX = moveDirX,
    dirY = moveDirY,
    dashing = isDashing,
    attack = isAttacking,
    hand = handState,
    gunReady = gunReady,
    stateHash = stateHash,
    normTime = normTime
});
```

### 3. 装备同步 (EQUIPMENT_UPDATE)

**触发时机**: 装备槽位内容变化时

**流程**:
1. 本地玩家装备变化 -> 触发 `onSlotContentChanged` 事件
2. 发送装备更新包（包含槽位哈希和物品ID）
3. 主机转发给所有其他客户端
4. 接收端应用装备更新

**应用装备** (`ClientPlayerApply.cs`):
```csharp
public async UniTask ApplyEquipmentUpdate_Client(string playerId, int slotHash, string itemId) {
    // 获取远程角色
    if (!clientRemoteCharacters.TryGetValue(playerId, out var remoteObj)) return;
    
    // 加载物品
    var item = await COOPManager.GetItemAsync(int.Parse(itemId));
    
    // 根据槽位应用
    if (slotHash == 100) COOPManager.ChangeArmorModel(characterModel, item);
    else if (slotHash == 200) COOPManager.ChangeHelmatModel(characterModel, item);
    // ... 其他槽位
}
```

### 4. 武器同步 (PLAYERWEAPON_UPDATE)

**特点**:
- 带去抖机制（200ms 窗口）
- 幂等性保证（相同武器不重复应用）
- 清理旧武器 Agent 避免残留

**应用武器** (`ClientPlayerApply.cs`):

```csharp
public async UniTask ApplyWeaponUpdate_Client(string playerId, int slotHash, string itemId) {
    // 去抖检查
    var key = $"{playerId}:{slotHash}";
    if (_lastWeaponAppliedByPlayer.TryGetValue(key, out var last) && last == itemId) return;
    
    // 清空目标槽位
    CoopTool.ClearWeaponSlot(model, socket);
    await UniTask.NextFrame();  // 等待销毁完成
    
    // 加载并应用新武器
    var item = await COOPManager.GetItemAsync(typeId);
    COOPManager.ChangeWeaponModel(model, item, socket);
    
    // 缓存弹丸预制体
    var gunSetting = item.GetComponent<ItemSetting_Gun>();
    LocalPlayerManager.Instance._projCacheByWeaponType[typeId] = gunSetting.bulletPfb;
}
```

## 重连机制

### 1. 客户端连接时

**文件**: `NetService.cs` -> `OnPeerConnected()`

```csharp
public void OnPeerConnected(NetPeer peer) {
    // 1. 创建玩家状态
    if (!playerStatuses.ContainsKey(peer)) {
        playerStatuses[peer] = new PlayerStatus {
            EndPoint = peer.EndPoint.ToString(),
            PlayerName = IsServer ? $"Player_{peer.Id}" : "Host",
            Latency = peer.Ping,
            IsInGame = false
        };
    }
    
    // 2. 主机发送现有玩家的血量信息
    if (IsServer) {
        // 发送主机自己的血量
        SendHealthInfo(peer, hostHealth);
        
        // 发送所有已连接玩家的血量
        foreach (var kv in remoteCharacters) {
            SendHealthInfo(peer, kv.Value.GetComponent<Health>());
        }
    }
    
    // 3. 发送本地玩家状态
    if (IsServer) SendLocalPlayerStatus.Instance.SendPlayerStatusUpdate();
}
```

### 2. 场景就绪机制 (SCENE_READY)

**触发时机**: 玩家进入新场景后

**文件**: `SceneNet.cs` -> `TrySendSceneReadyOnce()`

```csharp
public void TrySendSceneReadyOnce() {
    // 1. 检查是否已在场景中
    if (!LocalPlayerManager.Instance.ComputeIsInGame(out var sceneId)) return;
    
    // 2. 去抖：每个场景只发送一次
    if (_sceneReadySidSent == sceneId) return;
    
    // 3. 发送场景就绪包
    writer.Put((byte)Op.SCENE_READY);
    writer.Put(localPlayerStatus.EndPoint);
    writer.Put(sceneId);
    writer.PutVector3(position);
    writer.PutQuaternion(rotation);
    
    // 4. 异步发送外观数据
    SendPlayerAppearance();
    
    _sceneReadySidSent = sceneId;
}
```

### 3. 主机处理场景就绪

**文件**: `SceneNet.cs` -> `Server_HandleSceneReady()`

```csharp
public void Server_HandleSceneReady(NetPeer fromPeer, string playerId, string sceneId, Vector3 pos, Quaternion rot) {
    // 1. 记录该玩家的场景ID
    SceneM._srvPeerScene[fromPeer] = sceneId;
    
    // 2. 告诉新玩家：同场景中已有的其他玩家
    foreach (var kv in SceneM._srvPeerScene) {
        if (kv.Key == fromPeer) continue;
        if (kv.Value == sceneId) {
            // 发送 REMOTE_CREATE 包
            var w = new NetDataWriter();
            w.Put((byte)Op.REMOTE_CREATE);
            w.Put(playerStatuses[kv.Key].EndPoint);
            w.Put(sceneId);
            w.PutVector3(otherPos);
            w.PutQuaternion(otherRot);
            fromPeer.Send(w, DeliveryMethod.ReliableOrdered);
        }
    }
    
    // 3. 告诉同场景的其他玩家：创建新玩家
    foreach (var kv in SceneM._srvPeerScene) {
        if (kv.Key == fromPeer) continue;
        if (kv.Value == sceneId) {
            var w = new NetDataWriter();
            w.Put((byte)Op.REMOTE_CREATE);
            w.Put(playerId);
            w.Put(sceneId);
            w.PutVector3(pos);
            w.PutQuaternion(rot);
            kv.Key.Send(w, DeliveryMethod.ReliableOrdered);
        }
    }
    
    // 4. 对不同场景的玩家：发送 REMOTE_DESPAWN
    foreach (var kv in SceneM._srvPeerScene) {
        if (kv.Value != sceneId) {
            // 互相发送 DESPAWN 包
        }
    }
    
    // 5. 主机本地创建该玩家的远程角色
    if (!remoteCharacters.ContainsKey(fromPeer)) {
        CreateRemoteCharacter.CreateRemoteCharacterAsync(fromPeer, pos, rot, faceJson).Forget();
    }
}
```

## 玩家展示机制

### 1. 网络插值器 (NetInterpolator)

**功能**: 平滑玩家位置和旋转

**关键参数**:
- `posLerpFactor` - 位置插值因子
- `rotLerpFactor` - 旋转插值因子
- `hardSnapDistance` - 硬对齐距离阈值

**更新逻辑**:

```csharp
public void LateUpdate() {
    // 1. 误差过大时硬对齐
    if ((root.position - targetPos).sqrMagnitude > hardSnapDistance * hardSnapDistance) {
        root.SetPositionAndRotation(targetPos, targetRot);
        return;
    }
    
    // 2. 时间轴模式：直接应用插值后的位置
    if (useTimelineMode) {
        root.position = interpolatedPos;
        modelRoot.rotation = interpolatedRot;
    }
    // 3. 传统模式：Lerp 平滑
    else {
        root.position = Vector3.Lerp(root.position, targetPos, posLerpFactor);
        modelRoot.rotation = Quaternion.Slerp(modelRoot.rotation, targetRot, rotLerpFactor);
    }
}
```

### 2. 动画插值器 (AnimParamInterpolator)

**功能**: 平滑动画参数过渡

**同步参数**:
- `Speed` - 移动速度
- `MoveX/MoveY` - 移动方向
- `Dashing` - 冲刺状态
- `HandState` - 手部状态
- `GunReady` - 枪械准备

**应用逻辑**:
```csharp
public void Update() {
    if (animator == null) return;
    
    // 从缓冲区获取最新样本
    var sample = GetLatestSample();
    
    // 平滑过渡参数
    animator.SetFloat("Speed", Mathf.Lerp(currentSpeed, sample.speed, Time.deltaTime * 10f));
    animator.SetFloat("MoveX", Mathf.Lerp(currentMoveX, sample.dirX, Time.deltaTime * 10f));
    animator.SetFloat("MoveY", Mathf.Lerp(currentMoveY, sample.dirY, Time.deltaTime * 10f));
    
    // 布尔参数直接设置
    animator.SetBool("Dashing", sample.dashing);
    animator.SetInteger("HandState", sample.hand);
    animator.SetBool("GunReady", sample.gunReady);
}
```

## 重连后的玩家恢复

### 完整流程

1. **客户端重连**
   ```csharp
   NetService.Instance.ConnectToHost(ip, port);
   ```

2. **连接建立** (`OnPeerConnected`)
   - 创建 PlayerStatus
   - 发送现有玩家信息

3. **客户端上报状态** (`Op.CLIENT_STATUS_UPDATE`)
   ```csharp
   Send_ClientStatus.Instance.SendClientStatusUpdate();
   ```

4. **主机接收并创建角色** (`ClientHandle.HandleClientStatusUpdate`)
   ```csharp
   if (isInGame && !remoteCharacters.ContainsKey(peer)) {
       CreateRemoteCharacter.CreateRemoteCharacterAsync(peer, position, rotation, faceJson).Forget();
       
       // 应用装备和武器

           COOPManager.HostPlayer_Apply.ApplyEquipmentUpdate(peer, e.SlotHash, e.ItemId).Forget();
       }
       foreach (var w in weaponList) {
           COOPManager.HostPlayer_Apply.ApplyWeaponUpdate(peer, w.SlotHash, w.ItemId).Forget();
       }
   }
   ```

5. **主机广播玩家列表** (`Op.PLAYER_STATUS_UPDATE`)
   ```csharp
   SendLocalPlayerStatus.Instance.SendPlayerStatusUpdate();
   ```

6. **客户端接收并创建其他玩家**
   ```csharp
   case Op.PLAYER_STATUS_UPDATE:
       for (int i = 0; i < playerCount; i++) {
           // 解析玩家状态
           var st = ParsePlayerStatus(reader);
           
           // 创建远程角色

       }
   ```

7. **场景同步** (`Op.SCENE_READY`)
   - 客户端发送场景就绪
   - 主机返回同场景玩家列表
   - 创建/销毁对应的远程角色

## 关键优化点

### 1. 数据压缩

**位置压缩** (`NetDataExtensions.cs`):
```csharp
// 厘米精度，节省带宽
public static void PutV3cm(this NetDataWriter w, Vector3 v) {
    w.Put((short)(v.x * 100f));
    w.Put((short)(v.y * 100f));
    w.Put((short)(v.z * 100f));
}
```

**方向压缩**:
```csharp
// 使用 2 个 short 存储方向（球面坐标）
public static void PutDir(this NetDataWriter w, Vector3 dir) {
    var theta = Mathf.Atan2(dir.z, dir.x);
    var phi = Mathf.Asin(dir.y);
    w.Put((short)(theta * 10430.378f));  // 映射到 short 范围
    w.Put((short)(phi * 20860.756f));
}
```

```csharp
private const float WeaponApplyDebounce = 0.20f;
private readonly Dictionary<string, string> _lastWeaponAppliedByPlayer = new();
```

## 总结

这个 Mod 的玩家同步系统具有以下特点：

1. **双端架构**: 主机和客户端使用不同的数据结构，但逻辑对称
2. **按需创建**: 只在玩家进入游戏且在同一场景时创建远程角色
3. **高频同步**: 位置和动画以 67Hz 频率同步
4. **平滑插值**: 使用时间轴插值器保证流畅的视觉效果
5. **可靠重连**: 通过场景就绪机制和状态广播实现断线重连
6. **带宽优化**: 数据压缩、优先级系统、多通道传输
7. **去抖保护**: 防止重复应用装备和武器

核心流程：
- **创建**: 克隆本地角色 -> 禁用物理/AI -> 添加网络组件 -> 注册到管理器
- **同步**: 高频位置/动画 + 低频装备/武器 + 事件驱动的血量/伤害
- **重连**: 上报状态 -> 主机创建角色 -> 广播玩家列表 -> 客户端创建其他玩家
- **展示**: 插值器平滑 + 动画同步 + 血条显示
