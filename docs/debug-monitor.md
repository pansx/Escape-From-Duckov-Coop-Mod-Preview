# API 监控面板使用说明

## 访问地址

### 主机端
```
http://localhost:8080/debug
```
（使用配置的游戏端口，默认 8080）

### 客户端
```
http://localhost:9051/debug
```
（使用固定的调试端口 9051）

## 功能特性

### 实时监控
- 每 3 秒自动通过 AJAX 获取最新数据
- 无需手动刷新页面
- **智能更新**：只更新数据内容，不重新渲染卡片，保持展开状态

### 监控端点
1. **玩家列表** (`/api/players`) - 显示所有在线玩家
2. **AI 列表** (`/api/ais`) - 显示所有 AI 角色
3. **战利品箱** (`/api/lootboxes`) - 显示所有战利品箱
4. **投票状态** (`/api/vote`) - 仅在有活跃投票时显示
   - 数据条数显示为"通过人数/总人数"
   - 非 active 状态时自动隐藏

### 卡片展示
每个端点显示为一个独立的卡片，包含：
- 端点名称和路径
- 数据条数
- 最后更新时间
- 最后一条数据预览

### 交互功能
- **点击卡片头部**：展开/收起完整 JSON 数据
- **复制按钮**：一键复制完整 JSON 到剪贴板
- **格式化显示**：JSON 数据自动格式化，易于阅读

### 响应式设计
- 自适应布局，支持桌面和移动设备
- 卡片网格自动调整列数

## 使用场景

1. **实时调试**：监控游戏运行时的各项数据
2. **数据验证**：快速查看 API 返回的数据结构
3. **问题排查**：发现异常数据或错误信息
4. **性能监控**：观察数据更新频率和响应时间
5. **同步调试**：主机和客户端同时打开监控面板，对比数据差异

## 技术实现

- 纯 HTML + CSS + JavaScript
- 使用 `fetch` API 异步获取数据
- `setInterval` 实现定时刷新
- `navigator.clipboard` API 实现复制功能

## 注意事项

- 确保游戏已启动联机模式（HTTP 服务器会自动启动）
- 主机端使用端口 8080（或配置的游戏端口）
- 客户端使用端口 9051（固定调试端口）
- 浏览器需要支持现代 JavaScript 特性
- 复制功能需要 HTTPS 或 localhost 环境

## 调试技巧

### 对比主机和客户端数据
1. 主机打开：`http://localhost:8080/debug`
2. 客户端打开：`http://localhost:9051/debug`
3. 并排放置两个浏览器窗口
4. 观察数据差异，定位同步问题

### 快速访问特定端点
- 玩家列表：`/api/players`
- AI 列表：`/api/ais`
- 战利品箱：`/api/lootboxes`
- 投票状态：`/api/vote`
- 游戏日志：`/api/log` - 下载 latest.log 文件
